# 隠し職人と成長モーター

街の住宅脇の路地にメカニックマンを配置する。`hiddenMechanicSpot`は固定の街配置から歩いて到達できる場所を選び、地図や常設マーカーへ登録しない。通常のタップによる自動接近・会話で発見する。街のモブが職人の噂を話す。

初会話でメカニック・リンクを一個無料で取得する。装着は模型店のセッティング画面で行う。通常のモーター、選択個体、所持金は変更しない。再会話で増殖しない。

全段階20g、消耗なし・慣らし不要。最高段階の閾値はランキングの他レーサーの最大pt+1から導出する。同点1600ptやマスター称号750ptでは最終段階にならない。最高段階はテンペストと同じ回転数、ゼニスと同じトルク。そこまでの段階は星皇モーターより低い出力に抑える。

物理の特例にせず、九段階のパーツ定義を使う。熟練度の変化時に一個の所持品・個体を次のIDへ移す。外していても成長し、装着中なら選択個体と装備も引き継ぐ。レース中は装備を変更せず、レース画面を閉じた時に成長を反映する。これによりThree.jsの再生成とレースの再開始を防ぐ。

保存では熟練度を超える段階と複数段階の同時所持を拒否する。通常の所持パーツとして保存され、チュートリアル練習・ゲームオーバー復帰も既存のSavedGameの保護対象になる。既存セーブへ未発見のモーターを自動配布しない。

画像は`render-mechanic-motors.cjs`で各段階640×440のWebPを生成する。会話顔は専用512×512原画。歩行姿は共通の人物描画とサイズを使用する。

`mechanicMotor.test.ts`で到達経路、無料・一個、他パーツ保持、自動成長、レース中の据え置き、単独1位の条件、消耗なし、保存検証、練習での本編保護を確認する。
