# クリア後の巨大マスターコース

天頂決戦クリア後に4コースを解放。街の東側を増設し、既存施設の配置を保ちます。各760×420（通常屋外180×110の約16倍）、専用ゲート・照明塔・タイトル・記録看板・相談役を備えます。

| ID | 名称 | 主な狙い |
| --- | --- | --- |
| master-azure | 蒼天ライトニング・クロス | 高速舗装と砂地の両立 |
| master-crimson | 紅蓮ダスト・ストーム | 深い砂と砂利の接地・駆動力 |
| master-violet | 紫電ツイスト・ヴォルテックス | 高架旋回と短い連続S字・再加速 |
| master-gold | 金剛グランド・エンデューロ | 長距離・混合路面・三つのジャンプ |

全コースに舗装・砂・砂利、縦ループ、高架旋回、坂、物理ジャンプを備えた5レーンの一本道です。周回で引き延ばさず、1走で完結します。新コースのCPUには市販のクリア後構成を使い、速度倍率を掛けません。優勝8000円。解放条件は通常参加・対戦選択・オンライン対戦の入口で共有します。

モーター慣らし60秒・新品電池・星皇なしで、基準構成と各CPU構成の完走を確認しています。代表構成の横断比較では複数の構成がコースごとに最速となり、一つの比較構成で全4コース最速にはなりません。これは代表構成の比較であり全組み合わせの最適解探索ではありません。

## 検証

- 型チェック・Viteビルド成功。
- 解放条件・全レーン完走・記録保存・地図と歩行経路・旧クリア済みセーブ復元のテスト成功。
- Chromiumでデスクトップとスマホ幅の外観、クリア前ロック、開放後の地図4件とレース開始を確認。ページ例外なし。
- 全体テストでは既存の失敗3件（dirtCrawl、installedAppearance、raceAdvice）があり、変更前のチェックアウトでも同じ失敗を確認。今回のコース追加で変わる施設数のテストは新件数へ追従。
- 新4コースは既存コースと別ID。オンラインAPI側も4IDを追加し、既存記録を保持。
