# バランス監査を受けた修正（2026-11-06）

[監査](./2026-11-06-audit.md)で見つかったレーンの不公平、部品の役割の逆転、物理計算の不足を修正した。セーブの進行・所持品・出場権・大会結果は保持する。星皇の性能値・非消耗は変更していない。

## 実装

- 全コースで、レーン割当と見た目を保ちながら走行判定は共通の中央経路を使う。同じ装備・状態なら、開始レーンによらず失格位置・完走可否・タイムが一致する。緑川などの既存の公平化方式を全コースへ適用したもので、各レーンの見た目の曲率を完全に物理再現する方式ではない。
- ローラー摩擦は旋回時の壁荷重に加える。直線で常時空気抵抗のように差し引く処理をなくした。
- タイヤのグリップを、横方向の安定と旋回中の横擦れの交換関係にした。硬質タイヤは低グリップで速さを残す代わりに限界が低い。反発係数を着地の衝撃・速度損失に反映した。
- FMの前寄り重心を飛び出しの角度と着地衝撃に反映した。低いジャンプが有利な場面と、飛距離不足になる場面を残している。
- ブレーキ2種を補助パーツとして販売する。ソフトはひなたから、ハイグリップはゆうなぎから購入でき、ほしくずでも販売する。坂の入口に接触すると制動し、重量と補助枠を使う。平坦な直線では摩擦抵抗を加算しない。着地エリアを飛び越えるほど着地損失・姿勢の乱れが増えるため、速度を抑えることにも意味がある。
- タイヤとシャーシの追従性を掛け算せず、弱い側が残る加重調和平均で合成する。悪路の接地にはタイヤ側の追従も必要とし、強いシャーシだけで普通のタイヤを万能化できないようにした。トレッドの舗装抵抗は悪路では小さくなる。
- スイフト、サージ、テクニカルリング、K3悪路シャーシを役割に合わせて調整。通常の終盤モーターは回転数とトルクの交換関係を強め、最小の減速比だけで縦ループまで通せないようにした。成長モーターも同じ通常モーターの出力帯に合わせ、熟練度単独1位の解放条件・非消耗は維持した。
- スパークと流星の高出力電池は容量との交換関係を強めた。長距離では大容量型が有効になる。
- レジェンドのボディは軽量エアロ／旋回と悪路／重装悪路で役割を作り、混合路面でも使える性能にした。レジェンドCPUも車重に合うギアとモーターで走り、隠し速度補正で失速を回避しない。
- 図書館・パーツ説明・佐伯の案内を更新。新ブレーキは専用商品画像と装着モデルを用意した。

### 攻略と性能の検証

- 全10コースの全5レーン、監査で完走可否が分かれた3構成を回帰テストにした。
- 直線と旋回でのローラー摩擦、低グリップの速さと限界、低反発の着地、FMの低い飛び出し、ブレーキでのジャンプ距離・着地ストレスをテストした。
- 新品の4:1で通る車体でも、残量が減ると失速し5.2:1で完走できる例をテストした。4:1を単に弱める調整はしていない。
- 佐伯の軽量混成例は、タイタン＋3.5:1、エクリプス、アペックス、前中後ゼニス、ジャイロ・駆動PRO・クラウンスライド。現地購入可能で、発進0.3秒遅れでも複数シードの天頂で2位以内に入る。全レジェンドも完走する。
- 安定用部品を増やすほど速いとは要求しない。十分な制振がある車体では、軽量化や摩擦低減のほうが有効になる。
- 星皇の最高基礎性能・全コース完走・悪路向け混成の有効性は維持する。
