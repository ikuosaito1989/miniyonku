# 暁の実経路物理への調整

seed=42、慣らし60秒、新品電池、GO直後の発進。緑川の形状は変更していない。

基準構成はplayer=3コース、斗和=2コース。変更前は両車完走、player 122.9862秒、斗和122.9409秒。
プレイヤーのmass=.1295kg、drag=.00816、rollerFriction=.0256。
斗和はmass=.1335kg、drag=.00792、rollerFriction=.0337。
CPUの既存個体差も含み、斗和のfreeSpeed=10.37845に対しplayer=10.37088m/s。
軽量リヤローラー構成は122.6548秒、高トルク構成は121.7016秒で変更前から勝っていた。
コースアウトによる敗北ではない。

buildZenithTrackが描画と同じ実レーンの距離・傾斜・曲率を返し、stepDrivingがその値で位置更新と旋回抵抗を計算するようになり、以前の中央基準の僅差バランスが逆転した。
旋回抵抗はmass*v²*curvature*(rollerFriction*.5+tireScrub*.018)、ホイール抵抗はv²*curvature*.002*cornerDrag。
距離・傾斜・曲率の各寄与の厳密な分離は未実施。

フローティングホイールの用途に合わせ、wheel-zenithのcornerDragを.30から.25へ、重量を3gから2.5gへ変更（星皇の2g・.20より控えめ）。
この共通パーツを装備する全レーサーに同じ効果があり、直線（curvature=0）の抵抗は変化しない。
NPCの性能倍率、レーン別の補正、順位判定は変更していない。

変更後の基準構成は122.8953秒、斗和122.9409秒。固定seedの差は約.046秒と小さく、すべてのseedでの優勝を意味しない。
zenith.test.tsは7件成功。後続の既存不具合修正を含む最終検証では全409テスト成功。ここに記した走行秒数はホイール調整時点（螺旋出口の角度補間修正前）の測定。
