# 3Dの照明・材質・接地影

設定画面とレースのマシンは同じ `MachineModel` と `finishMachineMaterials` を使う。車体形状、装備の色・取り付け位置、走行物理、カメラ倍率はこの仕上げで変更しない。

## 照明と材質

`sceneLighting.ts` はACESトーンマッピング、暖色の主光源、青白い補助光、上下の環境光を共用する。面光源の反射には従来の `studioEnvironment` を使う。塗装はクリアコート、キャノピーは艶のある着色樹脂、金属は金属反射、タイヤは粗いゴムとして扱う。透過レンダーや画面全体の後処理は使わない。

`modelFinish.ts` は旧Phong材質を物理材質へ移行し、既存の装備色と塗色を保持する。入門軽ワゴンは粗さを高くして艶を控える。既存の金属とゴムの物理パラメータを維持する。曲面塗装の三角形は `AeroPaint` で投影法線と表裏を一致させ、塗装模様自体は影を落とさない。

## 影と負荷

設定画面は1024pxの影と焼き込みの接地影を使い、装備・角度・サイズの変更時だけ描画する。台は中間色のマットな材質とし、暗い部品とタイヤの接地を見やすくする。

レースは `RaceShadows` で路面のローカル座標へ接地影を配置する。坂・バンク・ループでは路面の向きに従い、ジャンプで薄くなり、脱落・コースの切れ目では消える。影のテクスチャは64×64を全車で共有する。

詳細な影は主人公付近の幅4.2mの範囲に絞り、スマホ512px・PC1024pxの影マップを使う。車体・キャノピー・シャーシ・タイヤを主な影の描画対象とし、小さなネジやスポークは省く。全景では詳細な影を落とさない。レースの解像度上限は既存の `raceRenderSize` を維持する。

`disposeSceneResources` は形状・共有材質・テクスチャ・影マップを画面終了時に解放する。装備を繰り返し替えても旧モデルのGPU資源を保持しない。

## 確認

`renderQuality.test.ts` で材質の違い、塗装面の法線、傾斜面の接地影、ジャンプ時の薄まり、共有資源の解放を確認する。形状・塗色・装備・走行時の動きは既存のモデル／塗色／raceMotionテストでも確認する。ブラウザではスマホ幅とPC幅でプレビュー・回転・装備の再設定・レース表示を確認する。描画呼び出し数は同じスタート画面で従来921回から1041回（約13%増）。これは実機のフレームレート測定ではない。

## コース構造と会場

`RaceCourseDetails` は実レーンの座標から厚さ29mmの下部、パネルの継ぎ目、レールの継手、六角固定具、高架の梁・支柱・脚・斜材を描く。下部は最大960区間、継手は最大約240区間に制限し、反復部品は `StaticInstances` でまとめる。ジャンプの開口に面を張らず、低いレーンの上に支柱を立てない。元の路面・側壁・走行サンプルは維持する。

`RaceVenueScenery` は通常会場の木質床、公式会場のタイル状床、区画化した観客席、安全柵、照明塔、整備用のピットを描く。屋外自由コースでは草地を維持する。観客は服・髪・帽子・腕・脚・椅子を分け、ピットは工具箱、工具、予備タイヤ、卓上マシン、収納、作業灯を備える。観客席と机の足元には共有の接地影を描く。追加の影付き光源は設けない。

会場は約50の描画バッチにまとめ、長いコースでは観客席を限られた幅の区画として配置する。コース導入の最初の全景には会場外周が見える余白を設ける。`courseVenueQuality.test.ts` で形状の有限性、走行サンプルの保持、ジャンプの開口、高架の構造、施設がコース外にあること、描画バッチ数の上限を確認する。

## 車体の細部・会場の動作・音

`MachineFineDetail` はシャーシの座金・六角留め具・溝、モーターへの配線、車体表面に沿う細い成形線を加える。機構と車体の既存寸法を維持する。`MachineSurfaceDetail` は64×64の共有データテクスチャをモデルごとに生成し、カーボンの織り目、ゴムの凹凸、金属の加工方向、塗装のごく細かな粗さを描く。装備色そのものは維持し、画像のダウンロードを必要としない。画面終了や装備交換でテクスチャをまとめて解放する。

`VenueAnimation` は最大96人の観客の頭・腕・手を12Hzで更新する。レース中は異なるタイミングで応援し、待機中は小さく顔を動かす。ピットの3人は道具を持って手元を動かし、スタート係はカウント・走行状態に応じて旗を動かす。移動経路やレース判定を持たない表示上の動作であり、インスタンス数や材質数を増やし続けない。`prefers-reduced-motion` では基本姿勢に戻して停止する。

`raceSoundscape` は状態の変化から発進・着地・プレイヤー付近の追い越しを検出し、同じ状態の再描画や音声再開で過去の効果音を重ねない。`RaceSoundLayer` は最大5台のモーターと転がり音を、距離・画面方向・速度・路面・空中状態に応じて合成する。ノイズ源は1つを共有し、短い効果音は最大12個まで。カウント音、音量・音ON/OFF、バックグラウンドでの休止と復帰を維持する。外部音源は使わず、走行計算には乱数や補正を加えない。

`machineSurfaceDetail.test.ts` は微細模様の共有と解放、`venueAnimation.test.ts` は固定設備の保持と動きを減らす設定、`raceSoundscape.test.ts` は効果音の一度だけの発生・距離・左右・空中・路面差を検証する。
