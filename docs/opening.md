# はじまりのシーン

新規開始またはセーブ初期化後、タイトルのゲーム開始から次の流れになる。舞台・会話・人物・素材はセイランのオリジナル。

1. 町の通りに到着した湊が、チビ四駆の町への期待を話す。
2. 最初の模型店を見つけ、実際の広域マップ上を歩いて入口へ向かう。
3. こもれび模型店に入り、小野寺 春夫に迎えられる。
4. 家具と人物を避けて作業台近くへ歩く。
5. 佐伯 匠から、無料の試走・完走賞・作業台・カウンター・パーツの組み合わせ・電池とモーターの状態について案内を受ける。
6. セッティング・購入・装着・初レースの実践チュートリアルへ進む（案内の省略も可能）。詳細は[チュートリアル](tutorial.md)。

`game/opening.ts` は会話と歩行のデータ・経路・段階の定義。PhaserのShopSceneが実際の町・店内で足を動かして歩く。町のカメラ倍率は通常と同じ。背景文字は追加せず、会話だけをOpeningSceneに表示する。会話はタップまたはボタンで進め、歩行は自動。歩く場面のみの省略・導入全体の省略も可能。非表示のタブでは歩行を進めない。足音と入店の短いオリジナル音は既存の音量・ミュート設定に従う。

保存するのはopeningStep（0〜OPENING_END）。完了後は再ログインで繰り返さない。古いセーブにフィールドがなければ完了済みとする。途中で再読込した場合は保存された会話や歩行の段階から再開し、所持品の配布・課金などは行わない。

既存プレイヤーも設定の「はじまりのシーンを見る」から見直せる。見直しは一時的なopeningTourで段階と元の場所を管理し、本来のopeningStepを変更しない。snapshotGameも元の場所を記録するので、見直し中に再読込しても進行を壊さない。省略すると元の場所の設定画面へ戻る。最後まで見た場合は、本来のデータを保護した練習チュートリアルへ進む。

検証：全247テスト・typecheck・build成功。実ブラウザのスマホ縦画面で到着・自動歩行・入店・案内・設定への移行・完了後の再起動・設定からの見直しを確認。横画面で案内途中からの再開と表示も確認。実行時エラーなし。
