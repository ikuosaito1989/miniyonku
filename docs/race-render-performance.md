# レース描画の計測メモ

2026-11-13、390×700 CSS pxのヘッドレスChromium（ソフトウェアWebGL）、天頂決戦・同じ5台の全体表示で比較した。実機iPhoneのFPS・GPU時間ではない。

| 指標 | 変更前 | 変更後 |
| --- | ---: | ---: |
| draw calls / フレーム | 1,399 | 1,271 |
| 三角形 / フレーム | 1,175,944 | 822,344 |

描画用のコース区間は、こもれび720→381、天頂4800→2590、蒼天4800→2564。走行サンプルは変更していない。ジャンプの開口・路面／レール色の変わり目は残し、曲率や姿勢変化が大きい箇所は元の密度を維持する。生成した描画用サンプルは同じコースの再挑戦時に再利用する。

車体は同じ車輪のスポークだけをインスタンス化し、車輪ごとの回転階層を維持する。設定画面のモデルは従来どおり。車体の他の静的部品、実機でのフレーム時間・GC・端末別GPU負荷、ロードの分割と資源解放の実測は引き続き必要。
