# はじめての操作案内

新規開始の入店シーンに続き、佐伯 匠が実際の操作を案内する。

1. モーターとタイヤを選び、性能や状態とセッティングの関係を知る。
2. カウンターで精密ギア4:1（350円）を購入する。通常の確認モーダルを使い、確定時だけ所持金を減らす。キャンセルは購入しない。
3. 作業台で購入したギアを自分で装着する。購入だけでは装着せず、装着済みの赤いランプを確認できる。
4. 店内のコースでカウント開始・GOに合わせた発進・レース・結果を体験する。通常の物理と賞金処理を使う。
5. 案内を終えると自由に遊べる。初勝利イベントはチュートリアル完了まで割り込まない。

tutorialStageを保存し、再読込しても購入段階や装着段階から続けられる。レース途中の再読込は発走前へ戻す。導入完了済みの旧セーブはチュートリアル完了扱いとし、勝手に開始しない。

設定の「操作チュートリアルを練習する」から既存プレイヤーも体験できる。練習開始前のSavedGameを保持し、練習中の自動保存も元のデータを保存する。終了・省略・再読込で本来の所持金、パーツ、消耗、大会進行、記録を変更しない。導入シーンの見直しからも同じ練習に進める。

検証はtutorial.test.tsで購入・手動装着・完走・報酬の一回性・保存移行・練習中のデータ保護・イベント割り込み防止を確認する。
